# Система управления консультациями

Индивидуальный учебный проект. ПР1 — основы Python, рабочее окружение и Git.

## Назначение

Приложение помогает студенту записаться на консультацию преподавателя,
а преподавателю — управлять расписанием и заявками. Оно должно уменьшить
число накладок в расписании и упростить согласование времени встречи.

## Целевая аудитория

- Студенты: поиск консультаций и запись на свободное время.
- Преподаватели: публикация расписания, подтверждение и отмена записей.
- Сотрудники учебного отдела: управление пользователями и просмотр расписания.

## Предметная область

Организация учебных консультаций. Преподаватель проводит консультацию по
определённой дисциплине и теме, студент выбирает свободное время и подаёт заявку.
У консультации есть начало, длительность, формат и статус доступности.
Индивидуальный временной слот предназначен для одного студента.

В ПР1 используется один учебный слот на завтра в 15:00 по местному времени
компьютера. Длительность — от 15 до 90 минут включительно. Имя преподавателя
и тема заданы в программе, студент вводит имя и длительность.
Данные существуют только в памяти во время запуска; при повторном запуске
создаётся новый демонстрационный слот.

## Основные сущности

| Сущность | Данные и связи в будущем приложении |
| --- | --- |
| Пользователь | Имя, учётная запись, роль студента, преподавателя или администратора |
| Дисциплина | Название, описание; связана с консультациями |
| Консультация | Преподаватель, дисциплина, тема, время, длительность, формат, статус |
| Запись | Студент, консультация, дата создания, статус подтверждения или отмены |

Один преподаватель ведёт много консультаций. Студент может иметь несколько
записей на разные консультации. На один индивидуальный слот допускается
одна активная запись. В ПР1 эти сущности представлены отдельными переменными.

## Основные функции

В ПР1 реализованы три функции предметной области:

1. **Проверка возможности записи** — `get_booking_status()`: свободен ли слот,
   не наступило ли время начала, допустима ли длительность. Возвращает
   разрешение или понятную причину отказа.
2. **Расчёт времени окончания** — `calculate_end_time()`: прибавляет минуты
   к началу консультации с помощью `timedelta`, учитывая смену дня.
3. **Подтверждение записи** — `create_confirmation()`: формирует сообщение
   с именами студента и преподавателя, темой, датой и временем встречи.

Функция `main()` объединяет их в законченный сценарий: ввод → проверка →
расчёт → занятие слота → подтверждение. Пустое имя, нецелая длительность
и длительность вне диапазона приводят к сообщению об отказе.

Использованы `str`, `int`, `float`, `bool`, арифметика, сравнения, `or` и `not`,
преобразование `int()`, строки,
`if`/`elif`, функции и импорт `datetime`, `timedelta`.
В коде приложения нет коллекций, циклов и собственных классов.
Вспомогательные тесты используют средства pytest.

## Запуск в Windows / PowerShell

Нужен Python 3.12 или новее. В этой рабочей папке `.venv` уже создано.

```powershell
.\.venv\Scripts\python.exe main.py
```

Для нового клона:

```powershell
git clone https://github.com/NikiVence/consult_managing.git
cd consult_managing
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe main.py
```

Если `python` указывает на MSYS2, создайте окружение обычным Windows Python,
указав полный путь к его `python.exe`. На исходном компьютере:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" -m venv .venv
```

Активация необязательна: прямой вызов интерпретатора из `.venv` не требует
изменения политики выполнения PowerShell. Само приложение использует только
стандартную библиотеку; `requirements-dev.txt` нужен для проверки.

Пример ввода: `Анна`, затем `45`. При запуске 15.09.2026 программа предложит
16.09.2026 15:00 и подтвердит окончание в 15:45; длительность — `0.75 ч.`,
значение доступности слота после записи — `False`.

## IDE, проверки и отладка

Откройте папку в VS Code. Расширения Python и Python Debugger рекомендуются
в `.vscode/extensions.json`; конфигурации интерпретатора, pytest и запуска
отладчика сохранены в `.vscode/`. Если IDE ранее запомнила другой Python,
выполните **Python: Select Interpreter** и выберите `.venv/Scripts/python.exe`.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
```

Пошаговый сценарий поиска ошибки и инструкции для IDE:
[docs/debugging.md](docs/debugging.md).
