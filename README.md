# Система управления консультациями

Индивидуальный проект Алиева Никиты, ЭФБО-01-24. Текущая версия — **ПР3: ООП**.

## Назначение и аудитория

Приложение помогает студентам записываться на консультации, а преподавателям
управлять расписанием. Предметная область — учебные консультации, их участники
и записи. В дальнейшем предусмотрены веб-интерфейс и роль учебного отдела.

## Что умеет программа

- Показывать расписание с сортировкой по дате.
- Искать консультации по теме или имени преподавателя.
- Показывать и добавлять студентов и преподавателей.
- Добавлять консультации с будущим временем начала.
- Проверять доступность выбранного слота.
- Записывать студента на 15–90 минут и рассчитывать время окончания.
- Отклонять занятой слот, прошедшее время и пересечения встреч
  одного студента или преподавателя.
- Показывать записи, отменять их и разрешать повторную запись после отмены.
- Сохранять данные в JSON и восстанавливать объекты между запусками.

## Запуск

В этой папке виртуальное окружение уже подготовлено. PowerShell:

```powershell
.\.venv\Scripts\python.exe main.py
```

При первом запуске создаётся `data/consultations.json`: студент Алиев Никита
(ID 1), преподаватель Иванова Анна Сергеевна (ID 2), две консультации
на завтра в 15:00 и 17:00. При последующих запусках загружаются сохранённые
данные; даты автоматически не сдвигаются. Новый слот добавляется пунктом 5.

Пример сценария:

1. Пункт **1** — посмотреть расписание.
2. Пункт **7** — ввести ID студента `1`, ID консультации `1`, длительность `45`.
3. Пункт **6**, ID `1` — убедиться, что слот занят.
4. Пункт **9**, ID записи `1` — отменить запись.
5. Пункт **7** — записаться на освободившийся слот повторно.
6. Пункт **0** — выйти; при новом запуске записи сохранятся.

Демонстрация без ввода и изменения пользовательской базы:

```powershell
.\.venv\Scripts\python.exe demo.py
```

На новом компьютере: Windows Python 3.12+, `python -m venv .venv`, затем
`.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt`.
Приложение использует стандартную библиотеку; зависимости нужны для проверок.

## Классы, атрибуты и методы

| Класс | Основные атрибуты | Основные методы и свойства |
| --- | --- | --- |
| User | id, name; атрибут класса role | __init__, __str__ |
| Student(User) | Наследуемые id, name; role | Переопределённый __str__ |
| Teacher(User) | Наследуемые id, name; role | Переопределённый __str__ |
| Consultation | id, teacher, topic, starts_at | __init__, __str__, is_future, validate_duration |
| Booking | id, student, consultation, duration_minutes, _is_cancelled | __init__, __str__, cancel, confirmation; ends_at, status, is_cancelled |

Student и Teacher являются разновидностями User — это **наследование**.
Их разные реализации `__str__()` вызываются одинаковым `print(user)` —
это **полиморфизм**. Изменение состояния записи через `cancel()` и чтение
через свойство `is_cancelled` показывают **инкапсуляцию**.

`Booking.student` ссылается на объект Student, `Booking.consultation` —
на объект Consultation, а `Consultation.teacher` — на Teacher. Эти связи
иллюстрируют композицию объектов. В памяти используются коллекции объектов,
а не словари с данными предметной области.

`@property` позволяет читать `booking.ends_at` и `booking.status` как
атрибуты. `@staticmethod` применён к проверке длительности, для которой
не нужен конкретный экземпляр. Конструкторы Student и Teacher наследуются.

## JSON и обработка ошибок

Один файл содержит `version`, `users`, `consultations`, `bookings`.
Связи записываются как `teacher_id`, `student_id`, `consultation_id`.
При загрузке ссылки восстанавливаются на уже созданные общие объекты.
Проверяются роли, ID, длительность, ссылки и конфликты активных записей.

Каждая изменяющая операция сохраняется сразу. Используется временный файл
и замена исходного после проверки. Ошибка сохранения откатывает изменение
в меню. Повреждённый JSON выводит ошибку и не перезаписывается автоматически.

Время локальное, без часового пояса. Статус записи — «Подтверждена» или
«Отменена». Авторизация и одновременная работа нескольких процессов
не реализованы: это учебное приложение для одного локального запуска.

## Проверки и IDE

```powershell
.\.venv\Scripts\python.exe -m pytest -v
.\.venv\Scripts\python.exe -m flake8 .
.\.venv\Scripts\python.exe -m ruff check .
```

Тесты проверяют прежние правила записи, создание классов и их связи,
отмену и повторную запись, пересечения, переход через Новый год,
восстановление JSON, повреждённые данные, ошибки записи файла и меню.
Временные базы тестов не затрагивают данные пользователя.

В VS Code выберите `.venv/Scripts/python.exe` и конфигурацию
«ПР3: система консультаций». Для изучения ООП поставьте breakpoint
в `create_booking()` или `Booking.cancel()` и посмотрите поля объектов.
