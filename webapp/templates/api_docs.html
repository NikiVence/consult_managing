API консультаций

Версия 1.0 · JSON · UTF-8

Вход создаёт серверную сессию с cookie sessionid. Перед POST получите /api/csrf/ и передайте csrfToken в заголовке X-CSRFToken. После входа токен меняется — получите новый.

Длительность — целое число 15–90. Время — ISO 8601 с часовым поясом. Один слот принимает одну активную запись. Пересечения встреч студента или преподавателя запрещены.

Регистрация создаёт только студента. Преподавателя назначает администратор. Доступ к записям ограничен участниками. Кэш списка: 15 секунд, сброс после изменения; доступность повторно проверяется при бронировании.

МетодПутьНазначение
GET/api/csrf/Получить CSRF-токен
POST/api/auth/register/Регистрация студента
POST/api/auth/login/Вход и создание сессии
POST/api/auth/logout/Выход из аккаунта
GET/api/auth/me/Текущий пользователь или null
GET/api/consultations/Будущие консультации: до 200, по дате
POST/api/consultations/Создать свой слот (только преподаватель)
GET/api/bookings/Свои записи; преподаватель видит записи к себе (до 200)
POST/api/bookings/Записаться (только студент)
POST/api/bookings/{booking_id}/cancel/Отменить свою запись; повторная отмена безопасна
GET/health/live/Процесс отвечает
GET/health/ready/Проверить БД и кэш

Пример записи

POST /api/bookings/
Content-Type: application/json
X-CSRFToken: токен из /api/csrf/

{"consultation_id": 1, "duration_minutes": 45}

Успех: 201 с объектом записи. Ошибки: 400 — поля; 401 — вход; 403 — права/CSRF; 404 — объект не найден; 409 — конфликт; 415 — тип содержимого; 429 — лимит попыток; 503 — сервис недоступен. Формат: {"error": "Сообщение"}.
