# Отладка ПР1

## Что проверялось

В `calculate_end_time()` правильное выражение:

```python
ends_at = starts_at + timedelta(minutes=duration_minutes)
```

Учебная ошибка — заменить `minutes` на `hours`. Программа продолжает
выполняться, но считает 45 часов вместо 45 минут. При начале
16.09.2026 15:00 ошибочный конец — 18.09.2026 12:00, правильный —
16.09.2026 15:45. Это логическая ошибка в единицах измерения.

## Повторение в VS Code

1. Откройте папку проекта. Выберите интерпретатор `.venv/Scripts/python.exe`.
2. В `main.py` поставьте breakpoint щелчком слева от строки
   `ends_at = starts_at + timedelta(minutes=duration_minutes)`.
3. Выберите конфигурацию «ПР1: запись на консультацию» и нажмите F5.
4. В терминале введите имя и `45`. Выполнение остановится до вычисления.
5. В Variables или Watch проверьте `starts_at` и `duration_minutes`:
   начало — завтра в 15:00, длительность — `45`.
6. Нажмите F10 (шаг с обходом). Посмотрите `ends_at`: завтра в 15:45.
7. Нажмите F5, убедитесь в выводе подтверждения и `Слот свободен: False`.
8. Временно замените `minutes=` на `hours=`, сохраните файл и повторите
   запуск с теми же данными. После F10 значение `ends_at` будет на 45 часов
   позже начала. Сравнение значения аргумента и единицы в `timedelta`
   показывает причину дефекта.
9. Верните `minutes=`, сохраните файл и повторите отладку. Проверьте тесты:
   `.\.venv\Scripts\python.exe -m pytest -q`.

Для защиты сделайте снимки остановки до шага, неправильного `ends_at`
и правильного `ends_at` после исправления. Перед сохранением изменений
проверьте, что учебная ошибка удалена.

## Выполненная проверка в терминале

Протокол `debugger_transcript.txt` получен реальным запуском стандартного
отладчика Python `pdb` для ошибочной и исправленной временных копий
функции из `main.py`. Команды `break`, `continue`, `next` и `p` задают
точку останова, продолжают выполнение, выполняют шаг и показывают значения.
Копии находятся в игнорируемой папке `.tmp`, основной файл содержит
правильный расчёт. Проверка в терминале не заменяет требуемую демонстрацию
в графическом отладчике IDE.
