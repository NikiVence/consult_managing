## 3. Индивидуальный проект

**Название:** «Система управления консультациями».
**Предметная область:** организация учебных консультаций студентов
с преподавателями. Пользователи — студенты, преподаватели и учебный отдел.
Основные сущности — пользователь, дисциплина, консультация и запись.
Согласование темы с преподавателем требует отдельного подтверждения.

**Репозиторий:** https://github.com/NikiVence/consult_managing

На ПР1 реализована запись одного студента на учебную консультацию.
Программа предлагает слот на завтра в 15:00, запрашивает имя и длительность
от 15 до 90 минут. Функция `get_booking_status()` проверяет доступность,
дату и длительность; `calculate_end_time()` рассчитывает время окончания;
`create_confirmation()` формирует подтверждение. После успешной проверки
слот становится занятым в пределах текущего запуска. Сохранение в базу
данных планируется на следующих этапах.

Использованы строки, целые и вещественные числа, логический тип, деление,
сравнения, преобразование `int()`, ветвления, логические операции, функции
и импорт объектов `datetime` и `timedelta`. Например, ввод `45` преобразуется
в число минут и в `0.75` часа. Коллекции, циклы и собственные классы
в основном приложении не используются.

## 4. Результат работы

Подготовлено виртуальное окружение Python 3.12, настройки VS Code,
`.gitignore`, README с описанием проекта и планом развития. Реализован
законченный консольный сценарий. Добавлены pytest-проверки разрешённой
записи, отказов, ввода и расчёта времени. Фактический результат выполнения
команд сохранён в `docs/verification.txt`: 22 теста пройдены, проверка
оформления Ruff завершена без ошибок.

Для упражнения по отладке в копии программы минуты намеренно заменены
часами в `timedelta`. При начале 16.09.2026 15:00 и длительности 45 минут
ошибочная версия получает 18.09.2026 12:00. Через отладчик `pdb` выполнены
остановка, шаг и просмотр переменных. После исправления получено
16.09.2026 15:45. Протокол сохранён в `docs/debugger_transcript.txt`.
Для обязательной демонстрации в IDE подготовлена конфигурация VS Code
и инструкция `docs/debugging.md`; демонстрацию студент выполняет отдельно.

Начальное состояние и результат разработки сохраняются отдельными
коммитами Git. Историю можно предъявить командой `git log --oneline`.
