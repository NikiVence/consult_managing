`git status`, `git log --oneline` и `git ls-remote origin refs/heads/main`.

## Яндекс Практикум

Отметки оставлены пустыми до подтверждения прохождения в аккаунте студента.
Методичка требует пройти эти материалы до индивидуального проекта.

- [ ] Погружение в Python.
- [ ] Простые типы данных.
- [ ] Ветвления.
- [ ] Импортируемые типы данных.
- [ ] Настройка рабочего окружения.
- [ ] Pytest.
- [ ] Система контроля и управления версиями.
- [ ] Требования к коду.
- [ ] Отладка программ.

В методичке есть фраза «первые три темы», но таблица и итоговый чек-лист
включают четыре: импортируемые типы данных также относятся к ПР1.
Коллекции, итерации, циклы и «Холодильник» относятся к ПР2.
