# ПР3: анализ предметной области и переход к объектам

Исходная версия в рабочей папке соответствовала ПР1: один сценарий,
отдельные переменные и функции. Самостоятельной версии ПР2 с JSON
и коллекциями в папке не было. В ПР3 продолжен тот же проект: добавлены
коллекции, меню и хранение данных, затем реализована объектная модель.
Прохождение ПР2 этим не подтверждается.

## Классы

| Класс | Атрибуты | Поведение |
| --- | --- | --- |
| User | id, name; атрибут класса role | Проверка ID и имени, __init__, __str__ |
| Student(User) | Наследует id, name; своя role | Переопределённый __str__ для студента |
| Teacher(User) | Наследует id, name; своя role | Переопределённый __str__ для преподавателя |
| Consultation | id, teacher, topic, starts_at; MIN_DURATION, MAX_DURATION | validate_duration, is_future, __str__ |
| Booking | id, student, consultation, duration_minutes, _is_cancelled | cancel, confirmation, __str__; свойства ends_at, status, is_cancelled |

У базового User, Consultation и Booking определён `__init__`.
Student и Teacher наследуют инициализацию от User. Объект Booking
хранит реальные объекты Student и Consultation; Consultation хранит Teacher.

## Перенос прежних функций

| Было в ПР1 | Стало в ПР3 |
| --- | --- |
| get_booking_status | create_booking, is_available, Consultation.is_future и validate_duration |
| calculate_end_time | Вычисляемое свойство Booking.ends_at |
| create_confirmation | Метод Booking.confirmation |
| main | Запуск меню, ввод, обработка ошибок, организация загрузки и сохранения |

Функции поиска и сортировки работают с коллекцией и остаются функциями
в `services.py`. Чтение и запись JSON — функции `storage.py`.
Проверка формата ввода — функции `utils.py`.

## Принципы ООП

- Наследование: Student и Teacher являются разновидностями User.
- Полиморфизм: `print(user)` вызывает переопределённый `__str__`
  соответствующего класса. Одинаковая операция даёт описание разных ролей.
- Инкапсуляция: `_is_cancelled` меняется методом `cancel()`;
  публичное свойство `is_cancelled` не имеет сеттера. Подчёркивание —
  соглашение Python, а не абсолютный запрет прямого доступа.
- Композиция: запись содержит ссылки на студента и консультацию.
- `@property` даёт доступ к вычисляемому времени окончания как к атрибуту.
- `@staticmethod` используется для проверки длительности, не зависящей
  от конкретного объекта. Собственный декоратор не нужен для этого сценария.

## Правила записи

Разрешена запись на будущую консультацию на 15–90 целых минут включительно.
На один слот допускается одна активная запись. Пересечения по времени
для одного студента или преподавателя запрещены. Встречи, заканчивающаяся
и начинающаяся в одну минуту, не пересекаются. Отмена сохраняет историю
и разрешает новую запись; повторная отмена безопасна.

Время локальное, без часового пояса. Статус означает состояние записи
(«Подтверждена» или «Отменена»), а не стадию проведения консультации.

## Хранение и ошибки

Единый JSON содержит версию схемы и три коллекции. При чтении сначала
создаются пользователи, затем консультации со ссылками на преподавателей,
затем записи со ссылками на студентов и консультации. Отсутствующие связи,
повторные ID, неправильные роли и конфликтующие записи считаются ошибкой.

Файл сохраняется через временный файл и замену исходного. Перед заменой
проверяется возможность обратной загрузки. При ошибке старый файл остаётся
целым. Меню изменяет копию объектов и принимает её после успешного сохранения.
Это приложение рассчитано на один запущенный процесс, без одновременного
редактирования базы несколькими экземплярами.

## Проверка задания

- Реализованы классы, объекты, методы, атрибуты, __init__ и __str__.
- Коллекции содержат объекты; связи восстанавливаются после загрузки JSON.
- Сохранён сценарий ПР1, добавлены поиск, сортировка, отмена и постоянное хранение.
- Основные функции и методы имеют аннотации типов.
- Тесты прежних правил адаптированы; добавлены проверки ООП, JSON и меню.
- Результаты фактических проверок находятся в `pr3_verification.txt`.
- Материалы Яндекс Практикума подтверждаются отдельно в аккаунте студента.
- Код, тесты, документация и отчёт подготовлены для хранения в репозитории.
