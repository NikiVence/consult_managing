# Локальные данные

При первом запуске `main.py` создаётся файл `consultations.json` с двумя
пользователями и двумя консультациями на следующий день. После этого
программа загружает существующий файл и не пересоздаёт расписание.

JSON содержит три коллекции: `users`, `consultations`, `bookings`.
Связи представлены идентификаторами; `storage.load_data()` восстанавливает
ссылки на общие объекты. Каждая успешная изменяющая операция сохраняется
сразу. Повреждённый файл не перезаписывается автоматически.

Для добавления актуальной консультации выберите пункт 5 в меню.
`demo.py` использует отдельный временный файл и не меняет эту базу.
